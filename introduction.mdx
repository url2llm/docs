Send a URL and choose the content you need: Markdown, HTML, links, screenshots, or structured data.

<Note>
This site describes the agreed draft contract. The current backend does not yet accept this request shape. The API reference is for review; its request runner is disabled.
</Note>

The request uses a `formats` object, shared browser settings in `sharedParams`, and optional settings for each output. Caching is off by default. Branding extraction is excluded.

Start with the [scrape guide](/guides/scrape), or open the API reference for request and response fields. The [OpenAPI file](/openapi.json) is the source for the endpoint reference.
