---
title: Quote and credits
description: Check the credit cost before scraping and understand billing outcomes.
---

`POST /v1/quote` checks the credit price for a scrape without fetching the page or charging credits. Send the same body you would send to `/v1/scrape`. The endpoint requires an API key with the `scrape` scope.

```bash
curl https://api.url2llm.com/v1/quote \
  -H "Authorization: Bearer $URL2LLM_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"url":"https://example.com","formats":["markdown"]}'
```

```json
{
  "success": true,
  "data": {"credits": 1, "free": false, "reason": "fresh_fetch"},
  "request_id": "req_example"
}
```

The response's `data` contains `credits`, `free`, and `reason`. A supported scrape currently quotes one credit with `free: false` and `reason: "fresh_fetch"`. A quote does not reserve credits or guarantee that the source page will succeed.

## Check operation prices

| Outcome | Credits |
| --- | ---: |
| Billable scrape, including a repeated URL | 1 |
| Successful map or search, including no matches | 1 |
| Billable crawl or batch page | 1 per page |
| Domain brand | 10 |
| Domain brand with measured style guide | 15 |
| Quote call | 0 |
| Blocked source response (`401`, `403`, `429`), timeout, or `5xx` | 0 |

A source page's `404` is charged. Credits are reserved before a request and released when its outcome is unbilled. Browser rendering and currently available extra formats have no surcharge. Every scrape fetches fresh content; there is no free cached-repeat tier.

All organization keys spend from the shared organization balance. The [dashboard](https://url2llm.com/dashboard) shows the current balance and usage; [Activity](https://url2llm.com/dashboard/activity) shows charges and released reservations for individual requests.

## Add credits

See [Billing and plans](/account/billing) for monthly allowances, prepaid credits, subscriptions, and automatic recharge. Billing changes require an organization owner or admin.

Quote accepts a scrape body only. It does not quote search or collections; their current prices are listed above. See [crawl and batch](/features/collections) for reserved credits and [domain branding](/features/brand-api) for credit rules.

Use an `Idempotency-Key` on product requests that can charge credits and collection creation you may retry. See [retries and idempotency](/guides/retries) to avoid duplicate work and charges.

A successful quote does not create a reservation or a price lock. Another key can spend the balance before your scrape runs. An insufficient available balance returns `402`; inspect [Billing](/account/billing#understand-available-and-reserved-credits) before retrying.
