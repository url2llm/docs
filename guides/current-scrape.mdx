---
title: Scrape a page
description: Fetch a page with the implemented API.
---

Send `POST /v1/scrape` with an API key in `Authorization: Bearer YOUR_API_KEY`:

```json
{
  "url": "https://example.com",
  "formats": ["markdown", "links"],
  "onlyMainContent": true
}
```

The response wraps the result in `data`. Page metadata is always included; outputs that were not requested are `null`. Request `screenshot` for a viewport capture or `screenshot@fullPage` for the full page.

JavaScript rendering is enabled by default. `maxAge` is `0` and `storeInCache` is `false` by default. Set them explicitly when you want cache reads or writes.

`POST /v1/quote` accepts the same request body and reports its current credit price without fetching the page. `POST /v1/map` discovers URLs on a site.

Structured JSON and summaries are not available yet. Use the API reference for the supported formats and complete request and response fields.
