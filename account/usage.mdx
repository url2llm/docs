Every API key spends from its organization's shared balance. Use [Overview](https://url2llm.com/dashboard) for totals and [Activity](https://url2llm.com/dashboard/activity) for individual request outcomes.

## Read credits from a response

For a scrape, `data.metadata.credits_used` reports the page charge. For search, use `data.credits_used`. Collection status reports `credits_used` and `reserved_credits`; crawl and batch results show each page's outcome. Domain branding has one total extraction price of 10 or 15 credits.

Keep the top-level `request_id` with the endpoint and request time when checking a request. Search also returns a numeric `data.request_id` for its usage record; it is distinct from the top-level API request ID.

## Understand activity

| Value | Meaning |
| --- | --- |
| Pending | Work has not finished |
| Status code | The source or execution outcome; `0` means no usable source status was recorded |
| Charged | Credits spent on the operation |
| Reserved | Credits held for work in progress |
| Released | Credits returned without a charge |
| Failure reason | An explanation of the unsuccessful outcome |

A source `404` is charged. Blocks, timeouts, and server errors release reserved credits. An error total therefore does not equal the number of refunded requests. Quote calls do not create charged activity, and requests rejected before execution may not appear in Activity.

## Check an unexpected charge

Check the organization, API key, URL, endpoint, and outcome. Repeating a URL with a new operation key is a new request; [idempotency](/guides/retries) replays one accepted operation without another charge. Revoking a key does not remove earlier charges.

The available balance is current, not the balance at the end of a selected usage period. See [billing](/account/billing#understand-available-and-reserved-credits) for monthly, purchased, and reserved credits.

Contact [support](mailto:support@url2llm.com) with the top-level `request_id`, organization ID, and request time. Never include the bearer secret.
