## Use the Playground

Organization owners and admins can use a revealable active API key in the Playground. The default selection is the oldest eligible key for the tool's scope. Choose another eligible key when you want usage attributed to a different service.

Scrape and Brand require the `scrape` scope. Map requires the `map` scope. If no eligible key is available, create one from API keys. A member without admin access cannot reveal the key needed by the Playground.

The Playground calls the same product endpoints as your application. Its requests use the selected key's scopes, the organization's rate limits, and the shared credit balance. It is not a free demo or a separate billing environment.

Run one representative page, inspect its requested outputs and source metadata, then use the same request settings in your integration. See [formats](/features/formats) for the available outputs.

## Account and product authentication

The dashboard's account requests use an organization-scoped user session. Administrative account operations include key management and billing changes. The Playground's product requests use an organization API key.

An API key cannot manage team membership, reveal another key, or change a subscription. A user session cannot replace the product API key on scrape, map, or quote. See [authentication](/getting-started/authentication) and [team permissions](/account/team-access#roles-and-permissions).
