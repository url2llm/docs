## Make a request

Get an [organization API key](/account/api-keys) and set `URL2LLM_API_KEY` as described in the quickstart. This request returns the main page content as Markdown:

```bash
curl https://api.url2llm.com/v1/scrape \
  -H "Authorization: Bearer $URL2LLM_API_KEY" \
  -H 'Content-Type: application/json' \
  -d '{"url":"https://example.com","formats":{"markdown":true},"onlyMainContent":true}'
```

Read `data.markdown` after checking the response's `success` flag. `data.metadata` preserves the source URL, final URL, source status, and credits used. The [quickstart](/getting-started/quickstart) includes cURL, Node.js, and Python examples.

## Choose an operation

| You have | You want | Use |
| --- | --- | --- |
| A public URL | Page content and selected outputs | [Scrape API](/features/scrape) |
| A starting URL or site | A list of candidate page URLs | [Map API](/features/map) |
| A planned scrape request | Its credit cost before execution | [Quote API](/guides/quote) |
| A public page | Its visible logos, colors, fonts, and component styles | [Branding output](/features/branding) from a scrape |

A scrape reads one page synchronously. Map discovers URLs without scraping each one. Your application selects pages and owns multi-page scheduling, indexing, storage, and refreshes.

## Before production

Read [authentication](/getting-started/authentication), [retries and idempotency](/guides/retries), and [errors and limits](/guides/errors). Check a representative page's output before scaling, keep its source metadata, and use a separate key for each service.

The API reference is generated from the implemented [OpenAPI contract](/openapi-public.json). The separate Draft API and [draft scrape guide](/drafts/scrape) describe proposed controls. Use the implemented guides for requests to the current API.
