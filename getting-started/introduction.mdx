## Make a request

The API base URL is `https://api.url2llm.com`. Send JSON with `Content-Type: application/json` and authenticate with `Authorization: Bearer YOUR_API_KEY`.

Get an [API key](/account/api-keys) and set `URL2LLM_API_KEY` and `URL2LLM_OPERATION_KEY` as described in the [quickstart](/getting-started/quickstart). This request returns the main page content as Markdown:

```bash
curl https://api.url2llm.com/v1/scrape \
  -H "Authorization: Bearer $URL2LLM_API_KEY" \
  -H 'Content-Type: application/json' \
  -H "Idempotency-Key: ${URL2LLM_OPERATION_KEY:?Set URL2LLM_OPERATION_KEY first}" \
  -d '{"url":"https://example.com","formats": ["markdown"],"onlyMainContent":true}'
```

Read `data.markdown` after checking the response's `success` flag. `data.metadata` preserves the source URL, final URL, source status, and credits used. The [quickstart](/getting-started/quickstart) includes cURL, Node.js, and Python examples.

## Choose an operation

| You have | You want | Use |
| --- | --- | --- |
| A public URL | Page content and selected outputs | [Scrape API](/features/scrape) |
| A starting URL or site | A list of candidate page URLs | [Map API](/features/map) |
| A query | Web source URLs, titles, and descriptions | [Search API](/features/search) |
| A URL list or website | Managed page collection with progress and results | [Batch and crawl](/features/collections) |
| A domain | Sourced brand facts and an optional measured style guide | [Domain branding](/features/brand-api) |
| A planned scrape request | Its credit cost before execution | [Quote API](/guides/quote) |
| A public page | Its visible logos, colors, fonts, and component styles | [Branding output](/features/branding) from a scrape |

A scrape reads one page synchronously. Map discovers URLs without scraping each one. Use batch for selected URLs or crawl for discovery and page collection. Both return a collection ID with progress, cancellation, and paginated results. Your application decides how to index, store, and refresh the content.

JavaScript rendering is enabled by default. Multiple supported formats can share one page fetch, and currently add no format or browser credit surcharge. Each new scrape fetches fresh content. Use [browser rendering](/guides/browser-rendering) for mobile, location, headers, and timing options.

## API access and credits

[Create an API key](/account/api-keys) in the dashboard. Signup supplies the Free plan's 1,000 monthly credits. Every key in an organization shares its balance.

Read [billing](/account/billing) for monthly allowances, prepaid top-ups, and optional auto-recharge, and [usage](/account/usage) to interpret charges.

## Prepare for production

Read [authentication](/getting-started/authentication), [retries and idempotency](/guides/retries), and [errors and limits](/guides/errors). Check a representative page's output before sending many requests, keep its source metadata, and use a separate key for each service.

Use the API reference for endpoint parameters and response schemas. The [OpenAPI specification](/openapi-public.json) is available for tooling and integrations.
