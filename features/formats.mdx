---
title: Formats and options
description: Choose the content and visual outputs returned by a scrape.
---

A scrape can produce several outputs from one fetched page. Request an array of format names:

```json
{
  "url": "https://example.com",
  "formats": ["markdown", "links", "branding"]
}
```

If you omit `formats`, the API requests Markdown. Select at least one output. Outputs you did not request are `null` in the response.

## Choose a format

| Format | Response field | Guide |
| --- | --- | --- |
| `markdown` | `data.markdown` | [Markdown and HTML](/features/markdown-html) |
| `html` | `data.html` | [Markdown and HTML](/features/markdown-html) |
| `rawHtml` | `data.raw_html` | [Markdown and HTML](/features/markdown-html) |
| `links` | `data.links` | [Links and assets](/features/links-assets) |
| `screenshot` | `data.screenshot` | [Screenshots](/features/screenshots) |
| `screenshot@fullPage` | `data.screenshot` | [Full-page screenshots](/features/screenshots#viewport-or-full-page) |
| `assets` | `data.assets` | [Links and assets](/features/links-assets) |
| `branding` | `data.branding` | [Branding](/features/branding) |

Use `screenshot@fullPage`, or request `screenshot` and set `screenshotParams.fullPage: true`, for a full-page capture.

## Combine formats

Start with Markdown for a reading or retrieval workflow. Add links to inspect related pages, HTML when document structure matters, or screenshots when visual state matters. Assets and branding are useful when your application needs page media or visual identity.

Extra outputs do not currently cost extra credits, but images and HTML can increase payload size. Screenshots, branding, and assets require JavaScript rendering. See [browser rendering](/guides/browser-rendering) for compatible settings.

A successful scrape produces every requested output. A scrape either returns all requested outputs or an error. Structured JSON extraction, summaries, and partial-result modes are not available.

## Adjust content and capture settings

Use [content filtering](/features/markdown-html#filter-the-content) to focus on useful sections. Choose [screenshot encoding and delivery](/features/screenshots) independently of the text outputs. All outputs share the source metadata described in [Scrape API](/features/scrape#response).

Request fields use camelCase. Use the API reference for supported request fields and response schemas.
