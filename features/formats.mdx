---
title: Formats and options
description: Choose the content and visual outputs returned by a scrape.
---

A scrape can produce several outputs from one fetched page. Request an array of format names or an object of enabled formats:

```json
{
  "url": "https://example.com",
  "formats": { "markdown": true, "links": true, "branding": true }
}
```

If you omit `formats`, the API requests Markdown. In a format object, omitted or false outputs are disabled. Select at least one output. Outputs you did not request are `null` in the response.

## Available outputs

| Format | Response field | Guide |
| --- | --- | --- |
| `markdown` | `data.markdown` | [Markdown and HTML](/features/markdown-html) |
| `html` | `data.html` | [Markdown and HTML](/features/markdown-html) |
| `rawHtml` | `data.raw_html` | [Markdown and HTML](/features/markdown-html) |
| `links` | `data.links` | [Links and assets](/features/links-assets) |
| `screenshot` | `data.screenshot` | [Screenshots](/features/screenshots) |
| `screenshot@fullPage` | `data.screenshot` | [Full-page screenshots](/features/screenshots#viewport-or-full-page) |
| `assets` | `data.assets` | [Links and assets](/features/links-assets) |
| `branding` | `data.branding` | [Branding](/features/branding) |

Use `screenshot@fullPage` through a format array. In a format object, enable `screenshot` and set `screenshotParams.fullPage: true`.

## Choose only what you need

Start with Markdown for a reading or retrieval workflow. Add links to inspect related pages, HTML when document structure matters, or screenshots when visual state matters. Assets and branding are useful when your application needs page media or visual identity.

Extra outputs have no current credit surcharge, but images and HTML can increase payload size. Screenshots, branding, and assets require JavaScript rendering. See [browser rendering](/guides/browser-rendering) for compatible settings.

A successful scrape produces every requested output. The current API does not return a mixture of successful and failed format results. Structured JSON extraction, summaries, and partial-result modes are not available.

## Content and capture settings

Use [content filtering](/features/markdown-html#focus-on-useful-content) to focus on useful sections. Choose [screenshot encoding and delivery](/features/screenshots) independently of the text outputs. All outputs share the source metadata described in [Scrape API](/features/scrape#response).

Request fields accept camelCase and snake_case. Use the implemented API reference for full request and response schemas; settings shown only in the Draft API are not a guarantee of current support.
