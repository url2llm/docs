`POST /v1/scrape` fetches one public page and returns the formats you request. The endpoint requires a key with the `scrape` scope. See [API keys](/account/api-keys) to create or rotate one.

## Scrape a page

<IdempotencyNote />

<CodeGroup>

```bash cURL
curl https://api.url2llm.com/v1/scrape \
  -H "Authorization: Bearer $URL2LLM_API_KEY" \
  -H 'Content-Type: application/json' \
  -H "Idempotency-Key: ${URL2LLM_OPERATION_KEY:?Set URL2LLM_OPERATION_KEY first}" \
  -d '{"url":"https://example.com","formats":["markdown","html","links"]}'
```

```javascript Node.js
import { request } from './url2llm.mjs'

const operationKey = process.env.URL2LLM_OPERATION_KEY
if (!operationKey) throw new Error('Set URL2LLM_OPERATION_KEY to the saved operation key')
console.log('Operation key:', operationKey)
const result = await request('/v1/scrape', {
  method: 'POST',
  operationKey,
  body: {
    "url": "https://example.com",
    "formats": [
      "markdown",
      "html",
      "links"
    ]
  },
})
console.log(result.data.markdown)
```

```python Python
import os
from url2llm import request

operation_key = os.environ['URL2LLM_OPERATION_KEY']
if not operation_key:
    raise ValueError('Set URL2LLM_OPERATION_KEY to the saved operation key')
print('Operation key:', operation_key)
result = request(
    '/v1/scrape',
    method='POST',
    operation_key=operation_key,
    body={'url': 'https://example.com', 'formats': ['markdown', 'html', 'links']},
)
print(result['data']['markdown'])
```

## Choose outputs

Provide a public URL and choose the [formats](/features/formats) your application needs. If you omit `formats`, the API returns Markdown. Provide format names in an array.

```json
{
  "url": "https://example.com",
  "formats": ["markdown", "links"],
  "onlyMainContent": true,
  "renderJs": true,
  "timeout": 30000
}
```

JSON extraction and summaries are unavailable. Do not send `jsonSchema` or `jsonPrompt`.

Request fields use camelCase. See the API reference for all parameters and the [OpenAPI specification](/openapi-public.json) for tooling.

Configure [content outputs](/features/markdown-html) and [browser settings](/guides/browser-rendering) to match your source.

Each new call fetches fresh content. Cache controls such as `maxAge`, `minAge`, and `storeInCache` are not accepted by the current API. See [quote and credits](/guides/quote) for billing behavior.

## Response

The response wraps the result in `data` and includes a top-level `request_id`. `data.metadata` reports `source_url`, `final_url`, `status_code`, and `credits_used`. It can also report the page title, description, author, language, publication date, and capture identifiers.

A successful response looks like this excerpt:

```json
{
  "success": true,
  "data": {
    "metadata": {
      "source_url": "https://example.com/",
      "final_url": "https://example.com/",
      "status_code": 200,
      "credits_used": 1
    },
    "markdown": "# Example Domain",
    "html": "<h1>Example Domain</h1>",
    "links": []
  },
  "request_id": "req_example"
}
```

Requested outputs are returned in `data`; outputs you did not request are `null`. `html` is cleaned content, and `raw_html` contains the fetched HTML. A successful scrape produces every requested output.

## Capture a screenshot

```json
{
  "url": "https://example.com",
  "formats": ["screenshot"],
  "screenshotParams": {
    "fullPage": false,
    "format": "webp",
    "quality": 80,
    "delivery": "base64"
  }
}
```

By default, screenshots are viewport captures encoded as JPEG with quality 80 and returned as inline data URLs. Set `fullPage: true`, or use `screenshot@fullPage` in a format array, to capture the full page. Do not combine `screenshot@fullPage` with an explicit `fullPage: false`.

For PNG, omit `quality`. For a public image link, set `delivery: "url"`. URL delivery waits for image storage, while base64 delivery does not. Public image URLs have no signature expiry and remain usable while the file is stored. Anyone with the URL can access the image. Read the [screenshot guide](/features/screenshots) for encoding, capture restrictions, and delivery options.

## Retries

Send an `Idempotency-Key` header to avoid repeating work or charges when retrying the same product request. Collection creation also supports idempotency. Reuse the key with identical inputs. A retry replays the saved response when available; otherwise it returns `409` with code `IDEMPOTENCY_KEY_ALREADY_ACCEPTED`, without executing again.

Saved responses may be delayed or unavailable. That conflict does not mean the original request failed. Reusing a key with different inputs returns `422` with code `IDEMPOTENCY_KEY_CONFLICT`. Use a new key only for an intentional new request. See [retries and idempotency](/guides/retries) for a complete retry policy.

Credits are reserved before execution and charged when completed. Blocks, timeouts, and server errors release the reservation. A returned source `404` page is charged. [Activity](https://url2llm.com/dashboard/activity) shows the failure reason, credits charged, and credits released.
